Diferentes tipos de agentes inteligentes

Aprende a describirle a una IA lo que necesita para crear un agente, un sistema en la nube y su base de datos. Recorre los módulos y termina con el quiz de 20 preguntas.

1. Tipos de agentes inteligentes

Un agente percibe su entorno con sensores, decide y actúa con actuadores para lograr un objetivo. Toca un tipo para ver su detalle.

Ciclo básico de cualquier agente

Percibir → Interpretar → Decidir → Actuar → Evaluar el resultado → volver a percibir.

3. Pedir un sistema en la nube: ejemplo clásico

Ejemplo: sistema de biblioteca (préstamos de libros). Estos son los componentes que debes definirle a la IA. Abre cada uno.

Prompt de ejemplo

Actúa como arquitecto de software senior. Genera un sistema web en la nube para una biblioteca.
Usuarios y roles: bibliotecario (admin), socio (lector).
Funciones: registrar libros, socios, préstamos y devoluciones; multas por retraso; búsqueda por título/autor.
Tablas: libros, autores, socios, prestamos, multas (relaciones 1:N y N:M libros-autores).
Base de datos: PostgreSQL. Backend: Node.js + API REST. Frontend: React responsivo.
Nube: contenedores Docker en un proveedor cloud (AWS/Azure/GCP), HTTPS, copias de seguridad diarias.
Seguridad: login con JWT, contraseñas cifradas, roles y registro de auditoría.
Entrega: estructura de carpetas, script SQL, código del API, pantallas y guía de despliegue paso a paso.
